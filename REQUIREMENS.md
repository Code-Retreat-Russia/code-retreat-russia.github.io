# 6. Анимации и интерактивность

Анимации являются важной частью задачи.

Используй **scroll-triggered animations**.

Но анимации должны быть осмысленными, а не декоративными ради декоративности.

Обязательно реализуй несколько типов взаимодействия:

### Scroll reveal

Секции и элементы появляются при попадании в viewport.

### Parallax / movement

Некоторые декоративные элементы могут двигаться с разной скоростью.

### Horizontal carousel

Для прошлых мероприятий.

### Trainer hover

Карточки тренеров должны реагировать на hover.

### Timeline interaction

Timeline мероприятия должна реагировать на скролл.

### Navigation

Сделай sticky navigation.

На desktop она может быть компактной и трансформироваться при скролле.

На mobile используй удобное меню.

### Micro-interactions

Добавь:

* hover states;
* плавные transitions;
* active states;
* subtle scale;
* opacity;
* translate;
* cursor interactions там, где они действительно уместны.
