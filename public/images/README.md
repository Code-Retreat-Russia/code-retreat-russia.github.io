# Изображения

Структура для реальных фото (сейчас нигде не обязательны — используются SVG-плейсхолдеры):

```
public/images/
  trainers/<id>.jpg    # id берётся из src/data/trainers.ts
  events/<id>.jpg      # id берётся из src/data/events.ts
  gallery/<n>.jpg      # произвольные кадры для секции «атмосфера»
```

Как подключить:

1. Положить файл по пути выше (jpg/webp, ~1200px по длинной стороне).
2. В `src/data/trainers.ts` / `src/data/events.ts` заполнить поле `photo` / `cover`.
3. Компоненты сами переключатся с плейсхолдера на `<img>` — правка вёрстки не нужна.
